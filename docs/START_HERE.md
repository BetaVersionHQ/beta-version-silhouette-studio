# Start here: no installs, no terminal

You need an AI coding assistant that can run commands on your computer. You paste one message. It downloads the studio,
installs anything missing (it warns you before a "Allow changes?" box or a password prompt: say Yes, and type your normal
computer password if asked) and makes a 10-second test film. You never type code.

## Copy and paste: set up

```
Set up this film studio for me: https://github.com/BetaVersionHQ/beta-version-silhouette-studio — download it, install anything that's missing, and make the 10-second test film.
```

The first time takes 10 to 30 minutes (it downloads a few GB). When it finishes, the test film opens on your screen.

## Copy and paste: your first film

```
Make a 60-second vertical short about two brothers fixing an old radio.
```

## Copy and paste: change something

```
Make Ben sound angrier in scene 2 and render again.
```

## Copy and paste: wide film

```
Make it a 3-minute 16:9 film instead.
```

## Copy and paste: white look

```
Use the white look with a shadow self.
```
